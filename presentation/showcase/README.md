# Project Showcase Guide

This folder contains the presentation and demonstration guide for the NIFTY Options ML Paper-Trading System.

## NIFTY Showcase Guide

The PDF provides a step-by-step walkthrough of the application, including:

- Main paper-trading dashboard
- ML Replay interface
- System architecture and workflow
- Machine learning and risk-management explanations
- Demonstration instructions
- Presentation script and technical Q&A

The project is simulation-only. Demonstration results should not be interpreted as real-world trading performance or evidence of profitability.
