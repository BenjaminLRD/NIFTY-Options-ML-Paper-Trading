# Data flow (overview)

Two data paths are never mixed. The full description is [application/docs/DATA_FLOW.md](../application/docs/DATA_FLOW.md).

| Path | Where it appears | Source | Used by models? |
|---|---|---|---|
| **Replay path** | dashboard `/ml` | Invented fixtures with 2031 dates, origin class `SYNTHETIC_FIXTURE`, replayed through the point-in-time gate (a record is visible only once its `available_at` time has passed) | Yes (the demonstration model) |
| **Synthetic live-like path** | dashboard `/` in Synthetic Mode | Quotes generated by a synthetic provider; the chart history is made up from a fixed seed | **Never** |
| **Provider path** | dashboard `/` in Real-Time Mode | Not connected; no provider is approved; provider data could at best be `UNVERIFIED` and cannot be traded | No |
| **Research data** | `research/` only | Real NSE end-of-day data, **not in this repository** and not read by the application | No (the application copies one result as a record) |

Outputs of a replay (written to the git-ignored `application/data/ml_replay/runN/`): `events.jsonl` (hash-chained), `decisions.jsonl`, `summary.json`, and an account state folder. A replay is built in `runN.partial` and renamed only when complete, so an interrupted run leaves no result.
